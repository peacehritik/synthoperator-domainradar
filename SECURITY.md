# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.4.x   | :white_check_mark: |
| < 2.4   | :x:                |

## Reporting a Vulnerability

We take the security and integrity of **SynthOperator DomainRadar** seriously.

If you believe you have discovered a security vulnerability (such as API credential exposure, injection risk, or bypass of risk gates), please **DO NOT** create a public issue on GitHub.

Instead, please send a detailed confidential report directly to:
📧 **support@synthoperator.com**

Please include:
1. Detailed description of the vulnerability.
2. Steps to reproduce or proof-of-concept payload.
3. Potential impact and attack vector.

We will acknowledge receipt within 48 hours and work with you to coordinate a responsible resolution before public disclosure.
